Proyecto Destacado

Proyecto 1: Fansite Dedicado a Twice

Este proyecto es un fansite dedicado al grupo de K-pop Twice, creado con el objetivo de ofrecer a los fanáticos un espacio interactivo y visualmente atractivo para explorar contenido relacionado con la banda. El sitio incluye secciones de noticias, biografía, discografía, galerías de fotos y videos, así como un foro para que los fans puedan compartir sus experiencias y opiniones.

Puntos clave: Estructuración HTML semántica, diseño receptivo (responsive) mediante CSS/SASS, arquitectura visual orientada a la experiencia de usuario y despliegue del proyecto.

Proyecto 2:Sitio Web para Servicio Técnico Ulicel

Este proyecto es un sitio web para un servicio técnico de Ulicel, creado con el objetivo de ofrecer a los clientes un espacio interactivo y visualmente atractivo para explorar contenido relacionado con el servicio. Puntos clave: Maquetación modular con soporte multidispositivo (laptop, tablet, móvil), optimización de recursos gráficos SVG e imágenes corporativas, integración de formulario de contacto/atención y control de versiones mediante Git.
